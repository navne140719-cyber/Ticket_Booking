🎟️ Ticket Booking Platform

A full-stack ticket booking application built using Java, Spring Boot, React.js, PostgreSQL, and Apache Kafka.

 🌐 Live Demo

https://glittery-empanada-015d82.netlify.app

🛠️ Tech Stack
- **Frontend:** React.js, JavaScript, CSS
- **Backend:** Java, Spring Boot, REST APIs
- **Database:** PostgreSQL, Spring Data JPA, Hibernate
- **Messaging:** Apache Kafka

✨ Key Features
- Browse movies and book tickets.
- Manage booking records.
- Handle concurrent booking requests using database transactions and row-level locking.
- Process booking notifications asynchronously using Kafka.
- Use Queue and Stack data structures for waiting-list and booking-history operations.
